# 0004. Defer rather than expand

**Status:** accepted
**Date:** 2026-10-06
**Affects:** every project

## Context
2026-05-24 — "lets go with A for now since the scope is already pretty big and file this under future development."

## Decision
When scope is already large, take the smaller option and record the remainder as future work out loud.

## Consequences
Features ship smaller and sooner. The cost is a known list of deferred work that must actually be tracked or it becomes permanent.
