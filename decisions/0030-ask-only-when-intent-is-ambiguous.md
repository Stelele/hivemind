# 0030. Ask only when intent is ambiguous

**Status:** accepted
**Date:** 2026-10-06
**Affects:** every project

## Context
2026-04-15 — "no I want maximum performance as the end result" (rejecting an earlier recommendation) · 2026-04-16 — "I want A."

## Decision
Once a choice has been offered and made, do not re-open it. Ask only when two readings lead to materially different work.

## Consequences
Decisions stick. The cost is that an early wrong choice is carried further before anyone notices.
